Assignment:
RRA wants to develop a database system to manage taxpayers, tax registrations, declarations, assessments, payments, audits, penalties, refunds, objections, enforcement cases, properties, vehicles, businesses, tax officers, and revenue collection centers. You are required to analyze the information provided and design a relational database named: REVENUE_ADMINISTRATION_DB The database must contain the 20 tables listed below. For every table: 1. Create the table using an appropriate table name. 2. Define suitable data types for all columns. 3. Define the primary key. 4. Define all necessary foreign keys. 5. Analyze and establish the correct relationships between the tables. 6. Apply appropriate constraints such as: o PRIMARY KEY o FOREIGN KEY o NOT NULL o UNIQUE o CHECK o DEFAULT 7. Insert at least 10 realistic records into every table. 8. Ensure that foreign-key values correspond to existing primary-key values. 9. Use meaningful Revenue Administration data. 10. Draw an Entity Relationship Diagram showing all relationships.
